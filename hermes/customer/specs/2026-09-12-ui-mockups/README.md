# UI mockups — 2026-09-12 design session

Static HTML screens produced during the brainstorming session that produced
`../2026-09-12-customer-ui-design.md`. Each file shows the options that were put
to the user and which one was chosen.

| File | Question | Chosen |
|---|---|---|
| `shell-structure.html` | App shell structure | **B — lifecycle sidebar** (nav = the scan cycle, status per stage) |
| `visual-identity.html` | Typography + colour personality | **B — graphite + violet**, 6px radius, light weights |
| `home-layout.html` | What the home screen leads with | **B — quarter checklist** |
| `report-gate.html` | How the report finalisation gate reads | **B — stepper header** + gate callout |
| `list-pattern.html` | List pattern for assets/scans/findings/team/audit | **B — card list** |
| `scope-versions.html` | How immutable scope snapshots read | **B — approved-scope hero + version history** |

Open any file directly in a browser; they are self-contained (no build step, no
external assets). They are design mockups, not the application — the real app is
built from the spec.

Originals live in the brainstorming companion's working directory
(`hermes/customer/.superpowers/brainstorm/…`), which is gitignored; these copies
exist so the design record survives in history.
