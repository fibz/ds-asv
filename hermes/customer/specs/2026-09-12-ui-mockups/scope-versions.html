Scope versions — how do immutable snapshots read?

A scope version is frozen once submitted, carries a hash, and only an approved version can back a scan. Question: how do you show a stack of them without inviting edits that can't happen?

A

Version cards, newest first

Each snapshot is a card with its state, contents and fingerprint. Immutability is obvious because every card is a sealed object, not a form. "What changed" is a line inside the card.
